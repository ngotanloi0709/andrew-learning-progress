# Note

## Basic command for using git
1. __git branch__ --> list all branches of repo
2. __git pull__ --> pull new version from current branch
3. __git status__ --> check changes of repo
4. __git add .__  --> add all changes made (ready to commit)
5. __git commit__ -m "message"
6. __git push__ origin main
